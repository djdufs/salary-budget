# 급여 예산

엑셀로 관리하던 `12월 급여 예산` 표를 그대로 옮긴 **단일 파일 웹 앱**입니다.
4자리 숫자 비밀번호(PIN)로 잠기고, Supabase에 저장되어 기기 간에 같은 예산을 이어서 씁니다.

- 주소: https://djdufs.github.io/salary-budget/
- 파일: `index.html` 하나 (빌드 없음)

## 화면

| 화면 | 내용 |
|---|---|
| 잠금 | 4자리 숫자 4칸. 처음이면 **설정**, 이후에는 **입력**. 틀리면 흔들림 + 안내 |
| 예산 | 수입/지출/잔액/납부 완료 요약, 수입·지출 목록, 달 이동 |
| 도구 | 새 달 만들기, 전월 항목 불러오기, JSON 내보내기/가져오기, 도움말, 이 달 삭제 |

- 항목 이름·금액은 눌러서 바로 수정, 빈 원 체크(✓)를 눌러 납부 완료 토글(완료 시 초록 채움 + `납입완료` 배지), 삭제는 6초 실행 취소
- 다크 모드, 모바일 레이아웃 지원
- 상단 `🔒`를 누르면 언제든 다시 잠깁니다. 잠글 때 화면의 예산 내용은 지워집니다.

## 저장

- 바꾸는 즉시(0.6초 뒤) Supabase에 자동 저장됩니다. 여러 번 고쳐도 저장은 순서대로 한 번씩 나갑니다.
- `이 기기에서 잠금 유지 (자동 잠금 해제)`를 켜면 그 브라우저의 `localStorage`에 PIN을 두고 다음 접속 때 번호 없이 엽니다. 끄면 저장된 PIN이 바로 지워집니다.
- 기기 두 곳에서 동시에 고치면 마지막에 저장된 쪽이 남습니다. JSON 내보내기로 백업할 수 있습니다.

## 데이터 구조

```
{
  version: 1,
  activeMonth: "2026-12",
  months: {
    "2026-12": {
      title: "12월 급여 예산",
      incomes:  [{ id, label, amount }],
      expenses: [{ id, name, amount, paid }]
    }
  },
  updatedAt: "2026-11-27T03:00:00.000Z"
}
```

## 서버(Supabase)

`index.html`은 아래 3개 RPC만 호출합니다. 테이블은 RLS로 잠겨 있고 `SECURITY DEFINER` 함수로만 접근됩니다.

| 함수 | 인자 | 반환 |
|---|---|---|
| `has_budget_pin()` | — | `boolean` — 이미 PIN이 설정되어 있는지 |
| `load_budget(p_pin)` | `text` | `{ status: 'empty' \| 'invalid_pin' \| 'ok', data?: state }` |
| `save_budget(p_pin, p_data)` | `text, jsonb` | `{ status: 'invalid_pin' \| 'ok' }` |

- PIN이 아직 없을 때 `save_budget`을 호출하면 그 PIN으로 등록되고 데이터가 저장됩니다.
- PIN은 함수 안에서 sha256 해시로 비교되고, 평문은 서버에 남지 않습니다.
